# Wesley's Portfolio

Minimal, professional personal portfolio site built with Next.js and NextUI.

## Technical Stack

- **Next.js 14** with App Router and static generation
- **NextUI** for components
- **TypeScript** for type safety
- **Tailwind CSS** for styling
- **Static export** - no backend, no database, no server required

## Setup

```bash
npm install
npm run dev
```

Open [[http://wesleyeze.com](http://wesleyeze.com)] to view the site.

## Build for Static Export

```bash
npm run build
```

This generates a static site in the `out` directory that can be deployed to any static hosting service (Vercel, Netlify, GitHub Pages, etc.).

## Content

All content is sourced from `PERSONAL.md`. Update that file and rebuild to update the site.
